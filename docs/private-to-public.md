# From private workflow to public case study

NovelBite preserves the technical shape of a larger private meal-planning workflow while removing everything unsuitable for a public repository.

| Area | Private workflow | NovelBite public case study |
| --- | --- | --- |
| Catalogue | Large real-world configurable menu | 296 fictional combinations |
| Branding | Private identity and themed artwork | Original NovelBite identity |
| History | Personal meal records | Browser-generated sample history |
| Configuration | Production project values | Generated empty config or separate demo project |
| Recommendation ideas | Novelty, ingredient cooldowns, shift pacing, queue diversity | Reimplemented as deterministic public modules |
| Mobile UX | Action-first queue, collapsed composer, safe modal close | Public responsive implementation |
| Deployment | Private static app | Git-integrated Cloudflare Pages showcase |

This separation allows the repository to demonstrate data engineering, ranking logic, privacy design, RLS and PWA delivery without publishing commercial menu content or personal data.
